# AI Evaluation Practice – Bengali

This repository contains personal practice samples related to AI response evaluation and data quality assessment.

The purpose of these samples is to demonstrate my ability to:

- Evaluate AI-generated responses
- Identify factual and linguistic errors
- Compare multiple AI responses
- Assess accuracy, relevance, clarity, and completeness
- Follow evaluation instructions carefully
- Provide concise and evidence-based feedback
- Identify common data-quality issues
